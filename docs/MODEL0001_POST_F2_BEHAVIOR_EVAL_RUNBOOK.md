# Model #0001 — post-F2 behavior evaluation runbook

Status: REQUIRED BEFORE PREFERENCE TRAINING

This stage performs NO training.

## Canonical comparison

Run on the Android phone:

```bash
cd ~/Android-Trainer
git pull
bash tools/phone_run_post_f2_behavior_eval.sh
```

Required local inputs in `/storage/emulated/0/Download`:

- `model0001-foundation-v3-source.atb`
- `model0001-f2-sft-final.atnckpt`
- `model0001-f2-sft.atsftstage`
- `model0001-f2-sft-stage-report.json`

The runner first reconstructs Model #0001 in PyTorch FP32 using the exact
normalized native tensor layout. It MUST reproduce the native masked SFT
validation CE for both Foundation-v3 and F2 final within the locked tolerance.
If that numerical preflight fails, no behavioral output is accepted.

After preflight, the exact same locked prompt suite is generated by both
models with greedy decoding:

- temperature: 0
- top-p: 1
- max new tokens: 48
- fixed prompt suite / fixed seed
- no optimizer
- no held-out project test split

Output:

`/storage/emulated/0/Download/model0001-post-f2-behavior-eval.json`

The report includes:
- raw Foundation-v3 response per prompt;
- raw F2 response per prompt;
- exact checkpoint/model identities;
- simple machine-checkable routing/content rules;
- paired improvements/regressions;
- human-review-only naturalness cases.

Machine rules are diagnostics, not a final preference-stage decision.

## Exploratory chat

Only after preserving the canonical eval report:

```bash
bash tools/phone_chat_model0001_f2.sh
```

This runs the frozen F2 final model locally with exploratory sampling
(temperature 0.8 / top-p 0.9 by default). Commands:

- `:reset`
- `:system <text>`
- `:save`
- `:quit`

The exploratory chat does not execute real tools. Raw
`<tool_call>{...}</tool_call>` output is intentionally shown so tool routing
can be inspected before app integration.

The transcript is stored at:

`/storage/emulated/0/Download/model0001-f2-exploratory-chat.json`

## Decision boundary

Do not start preference optimization until the canonical report has been
reviewed across all locked behavior dimensions. A lower SFT CE alone is not
sufficient.
